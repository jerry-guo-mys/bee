## M2 完成记录

### 已实现

- **SQLite**：`saas_workflow_templates`、`saas_workflow_template_versions`；`SaasSqliteStore` 上 list / resolve / create / add version / publish、`find_agent_instance_for_team_template`。
- **Postgres**：`migrations/0002_workbench_workflow_templates.{up,down}.sql`（与 SQLite 逻辑对齐，供云库使用）。
- **领域类型**：`src/saas/workflow_template.rs`（definition JSON、`ResolvedWorkflowTemplate` 等）。
- **内置模板**：`workflow_product_service::builtin_workflow_templates`；**合并规则**：`merged_workflow_templates_for_tenant` — **同 slug 时租户已发布模板覆盖内置**。
- **`GET /api/workflow-templates`**：返回合并列表；摘要含 `version`、`source`（`builtin` / `tenant`）。
- **`POST /api/workflows/start`**：支持 `template_version`（可选）；先解析租户已发布，再回退内置；任务写入 `assignee_ids`（团队内 instance 解析成功时）、`workflow_template_version`。
- **专家 API**：`GET/POST /api/admin/workflow-templates`、`POST .../:id/versions`、`POST .../:id/publish`；写 workspace audit（`workflow_template.*`）。
- **前端**：`/admin/workflow-templates`（流程模板管理页）、API 封装；工作台模板卡片展示 v 与「租户」标记。
- **测试**：`saas::sqlite::tests::test_workflow_template_create_publish`。

### 涉及文件（主要）

- `src/saas/workflow_template.rs`、`src/saas/mod.rs`、`src/saas/sqlite.rs`
- `src/bin/web/workflow_product_service.rs`、`src/bin/web/task_service.rs`、`src/bin/web/server.rs`
- `migrations/0002_workbench_workflow_templates.up.sql`、`.down.sql`
- `web-ui/src/pages/WorkflowTemplatesSettings.tsx`、`web-ui/src/lib/api.ts`、`api-types.ts`、`App.tsx`、`Layout.tsx`、`Workflows.tsx`

### 本地验证

```bash
cargo check --features web
cargo test test_workflow_template_create_publish --features web
cd web-ui && npm run build
```

## M3 完成记录（核心）

### 已实现

- **`src/bin/web/task_repository.rs`**：`TaskPersistenceMode`（`TASK_PERSISTENCE` / `BEE_TASK_PERSISTENCE`：`json` | `sql` | `dual_write`）；`list_tasks` / `get_task` / `upsert_task` / `append_tasks` / `patch_task`；SQL 路径 `INSERT ... ON CONFLICT DO UPDATE`；`dual_write` 写库后全量回写 `tasks.json`；读在 `sql`/`dual` 下走 SQLite。
- **`saas_tasks` 扩展列**（`ensure_column`）：`workflow_run_id`、`workflow_template_id`、`workflow_template_version`、`assignee_ids_json`、`group_id`、`coordinator_id`、`internal_group`。
- **状态映射**：`task_status_to_db` / `task_status_from_db` + 单测。
- **路由**：`api_tasks_*`、`api_task_board`、`api_workflows_start`、`task_coordinator_service` 全部经 `task_repository`，不再直接 `load_tasks`/`save_tasks`。
- **`AppState.task_persistence`**：启动日志打印当前模式。
